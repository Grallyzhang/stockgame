# 课程体系化扩展计划 v3：六章二十八课（60 天）

## 1. 概要

用户反馈：①课程不够系统、知识点太宽泛（参照 B 站《股票基础知识教程 132 讲》的标准体系）；②模式卡写「40-60 分钟」与实际单课约 5 分钟不符。

方案（用户已拍板）：
- 课程从「四章十四课 / 45 天」扩为 **「六章二十八课 / 60 天」**：新增「K 线体系」（单根 K 线 → 组合 → 缺口 → 形态）与「量价与指标」（成交量 → 量价背离 → 均线 → 金叉死叉 → MACD → 指标局限）两章 12 课，另加「估值浅识」与「毕业复盘」2 课；旧 t10–t14 整体后移改号。
- 技术分析立场 = **「教识别 + 当场打假」**：新增 3 次「预测 → 验证」环节，行情脚本故意安排「对、错、半对」三种结局，得出「信号有统计倾向但不保证」的诚实结论。
- 时长标注 = 模式卡不再写总时长，改为 **每课任务卡标注「约 X 分钟」**（每课 3–6 分钟）。

沿用既有约束：评价基于学习行为而非盈亏；奖励只解锁工具；简化 A 股规则（T+1、±10%、佣金 0.1% 最低 1 元）不变；纯前端 ES modules 无构建。
